## Installation

You can install `napari-mask-generator` via [pip]:

```bash
pip install napari-mask-generator
```

If napari is not already installed, you can install `napari-mask-generator` with napari and Qt via:

```bash
pip install "napari-mask-generator[all]"
```


To install latest development version:

```bash
pip install git+https://github.com/tomcodewizard/napari-mask-generator.git
```
